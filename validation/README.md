# Current release: unified finite-map statistics (4 November 2026)

The current producer is `KTZ_validation.py` (with the matching executed notebook).
It writes `validation/outputs_rework_20261104/` and `validation/figs_rework_20261104/`.
The single-element statistic is xi_b: matched response, per-map annular projection,
valid unordered pairs, and normalisation after summing. The multi-element statistic
is the projected zero-lag Xi_AB. Its same-event diagonal is source-integrated with
converged log-variance age quadrature; the ring correction and distinct-event term
retain the documented local approximations.

Current synthetic products and checks are in `outputs_rework_20261104/`; the legacy
`outputs/` directory and older replot helpers describe the known-profile experiment,
not the current figures. The numerical comparison is not a calibration of the
observational null/EB likelihood. Observational Table 3 and posterior arrays are unchanged.

From the repository root, install `validation/requirements.txt`, then run:

```sh
OMP_NUM_THREADS=1 MKL_NUM_THREADS=1 OPENBLAS_NUM_THREADS=1 NUMBA_NUM_THREADS=2 KTZ_VALIDATION_ROOT=$PWD python KTZ_validation.py
python -m validation.test_cross_diag
python -m validation.test_unified_prediction
```

The producer can replay the released caches to redraw all five current validation
figures; without caches it regenerates the controlled fields using the original
seeds. The per-realisation multi-element cell arrays are not included (about 206 MB);
they can be regenerated by running with a new `KTZ_RUN_TAG`. They are required only
for the optional ensemble-mean diagnostic. Do not mix outputs from different tags
or alter scientific parameters while reusing a cache. The diagonal cache records
and checks its integration configuration.

For additional checks, run `python -m validation.test_unified_ops`,
`python -m validation.rework_cross_diag validation/outputs_rework_20261104`, and
the representative ring diagnostics documented below. The archived scalar
convergence variants are in `outputs_rework_20261104/convergence/`.

The current RMSEs are 0.0045635221 (single-element full window) and 0.0143846405
(multi-element). The latter retains an unexplained element-dependent residual;
the targeted ring tests are not a rigorous error bound for every element pair.

# KTZ Paper III — numerical validation with the unified finite-map statistic (2026-11-03)

Section 3 now uses the single statistic of Sec. 2.3.4 for simulation and prediction alike:
response Psi (Gaussian beam FWHM_b = 2 dx, sampled at the valid cell centres) -> annular projection P with
the annular mean estimated from every realisation (17 annuli of 0.673 kpc for the single-element maps,
71 annuli of 0.167 kpc for the multi-element maps) -> sums over the unordered valid-cell pairs P_b ->
normalisation last.  The phase-sector window and the fixed-midpoint-radius check (appendix) are the same
estimator with a different pair window.

* `KTZ_validation.py` (entry point; `KTZ_validation.ipynb` is generated from it with
  `python3 validation/py2nb.py KTZ_validation.py KTZ_validation.ipynb`).
* `validation/ktz_unified_ops.py` — projector, pair windows, numba pair sums, exact polar-harmonic Gaussian
  smoothing, Gram-form covariance pass.
* `validation/ktz_unified_scalar.py` — single-element prediction: same-event Gram integral with the exact
  one-point rate on the 3-15 kpc support, isotropic C_D as a parent-position Gram integral (axisymmetric
  parent rate), complete transported mean projected before its outer product; modulated-parent C_D diagnostic.
* `validation/ktz_unified_cross.py` — projected zero-lag Xi_AB (annular-mean correction with exact
  annulus pair-offset counts; exact projected transported means).
* `validation/test_unified_ops.py` — independent checks (run `python3 -m validation.test_unified_ops OUT.json`).
* Outputs: `validation/outputs_unified_20261103/` (raw regenerated fields, cached prediction, statistics,
  metrics `validation_metrics_unified.json`, tests, convergence); figures: `validation/figs_unified_20261103/`
  (copied to `figs/validation_unified_*.png` for the manuscript).
* Runs are resumable: raw fields, the prediction and the cross covariances are cached with atomic writes;
  the regenerated fields are audited against the archived statistics of the earlier prescription.
* Run (2 cores, single-threaded BLAS):
  `OMP_NUM_THREADS=1 MKL_NUM_THREADS=1 OPENBLAS_NUM_THREADS=1 NUMBA_NUM_THREADS=2 KTZ_VALIDATION_ROOT=$PWD python3 KTZ_validation.py`

The material below describes the earlier known-profile prescription; its outputs in `validation/outputs/`
